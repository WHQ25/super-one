# Apple Quick Look studio lighting

`studio_lighting_objectmode_v002.exr` is provided by Apple for matching AR
Quick Look's object mode lighting in third-party apps.

- Source: https://developer.apple.com/sample-code/ar/studio_lighting_objectmode_v002.exr
