A batch of platform polish that makes SuperOne feel more at home on every OS — and gives you more control over how it looks and updates.

### Native Windows title bar

Windows gets a custom title bar with overlay window controls, so the app chrome matches the rest of the UI instead of the default system frame. The window feels like one continuous surface, top to bottom.

### Terminal themes and a real appearance page

A dedicated **Appearance** settings page brings terminal color schemes and font selection together in one place. Pick a palette and a monospace face for the integrated terminal and the rest of the editor surfaces follow.

### Switch update channels at runtime

You can now choose your update channel — alpha, beta, or stable — from settings, and switch it live without reinstalling. Opt into early builds or settle onto a quieter track whenever you like.
