### 原生 Windows 标题栏

Windows 用上了自定义标题栏与覆盖式窗口控件,应用窗口与其余 UI 浑然一体,不再是系统默认边框。整个窗口从上到下像一块连续的界面。

### 终端主题与独立外观页

新增的 **外观** 设置页把终端配色与字体选择集中到一处。为集成终端挑一套配色和一款等宽字体,其余编辑器界面随之统一。

### 运行时切换更新通道

现在可以在设置里选择更新通道 —— alpha、beta 或 stable —— 并实时切换,无需重装。想尝鲜早期版本,或回到更稳的轨道,随时切换。
