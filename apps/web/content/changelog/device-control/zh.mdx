一个在写移动应用的 agent,应该能看着它跑起来。

### 读结构树,读不到才回退到像素

iOS 模拟器助手读取语义化的辅助功能树,识别到的屏上文字以普通 UI 树的形式呈现,而不是另一份 OCR 结果 —— 于是 agent 只需查询一种结构。只有在应用什么都没描述的地方才去读像素。快照的身份是结构树与画面帧共同构成的指纹,因为两者中任何一个单独看都可能过期而另一个已经变了;元素引用会 pin 到它来源的那个快照上,于是过期的引用会明确失败,而不是点错东西。

### Android 走同一道接缝

Android 设备被发现后出现在同一份目录里,通过同一道 agent 接缝驱动,配以中立的画面与输入模型和实时视频流。一个连接服务所有观看者,真机按市场名而不是零件号命名,模拟器随应用一起关闭。

### 三个来源,一个面板

iOS 模拟器、Android 和投屏中的 iPhone 出现在同一个跨平台设备面板里,背后是按平台路由的 IPC 门面。agent 从分层目录中请求设备并获得控制授权;每个设备标签有自己的身份,于是一个会话可以同时持有两台设备,并指明某次调用是给哪一台的。

### 预览就是取景器

浮在聊天之上的预览,和 agent 看到的是同一个表面。你在看的和它在操作的是同一件东西,不是两件。
