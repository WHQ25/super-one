一个能读你代码、却读不了你正在调试的那个页面的 agent,只有一半用处。活动面板现在内置了一个真正的浏览器,而这个浏览器接进了每个 harness 都会继承的工具面。

### 一个你真的会用的浏览器

标签页按会话隔离,书签支持文件夹,地址栏带历史自动补全,`Cmd/Ctrl+D` 收藏,`Cmd/Ctrl` + 点击在新标签打开,还有页面缩放和加载进度条(不再是一个转圈的刷新图标)。弹窗式登录会被重定向回同一个标签页,于是 OAuth 流程能走完而不是凭空消失。证书报错的站点可以在警告后继续进入,不再是死路。

### 指着某个东西,直接交给 agent

标注模式让你点选页面上的元素并附到聊天输入框。webview 的右键菜单承担其余部分 —— 复制图片、把图片直接拖进对话,或者触发一个快捷标注动作。

### 同一个浏览器,以 MCP 工具的形式

`browser_tabs`、`browser_snapshot`、`browser_act`、`browser_query`、`browser_evaluate`、`browser_network` 等工具注册在 SuperOne 的 MCP 面上,于是 Claude、Codex 和其他每个 harness 都能用上,自己不必再带一个浏览器。快照可以按区域选取,支持 console grep 和 TOON 输出以控制体积;选择器做了稳定化处理,匹配歧义会被报告出来而不是悄悄选一个;type 工具的摘要里会遮蔽密文。网络录制是按需开启的;另有一层基于 CDP 的自动化通道放在实验设置后面,用于合成事件表达不了的场景。
