浅色模式此前一直是"把暗色主题的亮度调高"。这正是它始终不太像被设计过的原因。

### 反转 chrome,而不是调亮暗色

chrome 的关系在 token 层被反转:在暗色下最深的表面,在这里变成最浅的;层级是重建的,不是继承来的。每一条 token 通道都被显式写入,于是不会有某个值悄悄回落到暗色默认值。

### 墨色按对比度推导

品牌填充色加深了,而落在它上面的文字颜色是由填充色按对比度算出来的,不是挑一次然后指望它在所有色相下都成立。品牌色相由用户自由调节,所以手工挑一个前景色对大部分取值都会是错的 —— 在极高亮度下,填充色物理上就承载不了颜色,推导过程把这一点考虑了进去,而不是产出一个读不清的色块。
