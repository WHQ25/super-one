SuperOne picks up a new look — and the design system underneath it got a thorough cleanup to make it possible.

### Liquid Glass

Turn on **Liquid Glass** in settings for a translucent dark theme: frosted, layered surfaces with native window vibrancy and depth. It's opt-in, gated entirely behind `AppSettings.liquidGlass`, so the classic opaque theme stays exactly as it was unless you reach for it.

### A cleaner token foundation

Behind the scenes, the design-token system was consolidated: a neutralized accent token, a dedicated highlighted token, and a paired set of **success / warning / error** semantic colors that read correctly in both light and dark. The coding layout also moved to a floating-card treatment with refined spacing and resize affordances.
