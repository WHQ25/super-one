长会话很耗 token,而以前你往往要等到请求被限流才发现。这次更新把用量和额度直接放到你工作的地方 —— 并在请求切换模型的那一刻就告诉你。

### Claude 与 Codex 实时用量

Sidebar 现在直接从 provider 读取真实额度。Claude 账户展示来自 OAuth 用量接口的实时数据;Codex 账户则呈现 ChatGPT 订阅的额度上限,以及 app-server 上报的按账户 token 用量。下一轮对话还剩多少余量,不再靠猜。

### 模型回退可见

当请求无法在你选定的模型上运行、agent SDK 回退到其他模型时,消息上会就地出现回退提示。是哪个模型真正作答,你始终清楚 —— 不再有静默替换。
