The fourth engine took days rather than weeks, which was the point of declaring harness differences as data.

### A full backend, not a shim

OpenCode arrives with its native commands and session controls, agent selection, and the `init` command wired to the same session lifecycle every other harness uses. Compact, rewind and fork are all supported, so a session can be wound back or branched the way you would expect from the others.

### MCP, including OAuth

MCP integration ships with the OAuth authentication flow, so servers that require a browser round trip can be attached without leaving the app.

### Shell mode and sharing

Shell mode is available inside the session, session titles synchronize with the host, and OpenCode's own session sharing commands are exposed rather than hidden.

### One selector

The OpenCode agent moves into the shared model selector. Turning on a fourth engine adds entries to a list you already know — it does not add a fourth place to look.
