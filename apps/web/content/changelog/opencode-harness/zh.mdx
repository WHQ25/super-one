第四套引擎花的是几天而不是几周,这正是"把 harness 差异声明为数据"的意义。

### 一个完整后端,不是垫片

OpenCode 带着它的原生命令与会话控制、agent 选择,以及接到同一套会话生命周期上的 `init` 命令到来。compact、rewind 和 fork 全部支持,于是一个会话可以像在其他引擎上那样被回退或分叉。

### MCP,含 OAuth

MCP 集成随附 OAuth 认证流程,那些需要走一趟浏览器的服务不必离开应用就能挂上。

### Shell 模式与分享

会话内可用 shell 模式,会话标题与宿主同步,OpenCode 自己的会话分享命令被暴露出来而不是藏起来。

### 同一个选择器

OpenCode 的 agent 移进共享的模型选择器。打开第四套引擎,是在你已经熟悉的那个列表里多几项 —— 而不是多出第四个要去看的地方。
