A plan you can only approve or reject is a yes/no question about a paragraph you wanted to change one line of.

### Comments anchored to a selection

Select any span of the plan and leave a sticky note on it. The selection stays highlighted while the note is open, so the comment and the text it refers to are visibly bound together rather than being a list of remarks at the bottom.

### Multi-color highlighter pens

Each comment gets its own highlighter color, so several notes on the same paragraph stay distinguishable. The palette is theme-aware — the sticky colors are derived for both light and dark rather than being a fixed set of pastels that vanish in one of them.

### The agent reads the markup

Comments travel back with the plan approval, so the model receives the specific objections attached to the specific lines instead of a summary you had to write yourself.
