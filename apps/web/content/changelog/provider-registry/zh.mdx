以前每接一家新厂商,就意味着 provider 代码里多一个分支。现在注册表描述的是"这个端点能做什么",应用去读这份描述。

### 端点 family

平台声明的是若干个端点 family,而不是一个 base URL。于是一家在不同路径上分别提供 chat completions、Anthropic 形状路由和图像协议的厂商,是一个条目而不是三个。自定义平台的端点按 API key 分别存储,连接测试统一走第一个端点的模型列表;另有一个 `openai-responses` 开关,覆盖那些需要 Responses 形状来兼容 Codex 的 provider。

### 模型自己发现自己

把 SuperOne 指向一个 OpenAI 兼容端点或一个 relay,它会列出该端点实际提供的模型。发现到的模型对照本地 models.dev 目录分类,于是上下文窗口、推理支持和价格来自目录,而不是一张手工维护的表 —— 自定义模型和发现的模型都能看到目录详情。模型图标按目录别名匹配,所以你自己加的模型也能拿到它的品牌标识。

### 自定义平台完全可编辑

能力、密钥和模型映射都能事后修改。自定义模型直接在模型列表里管理,媒体能力由你启用的模型推导,推理能力则一路传到 effort 选择器。自定义 provider 的启动开销也做了削减,加一个不再拖慢首次启动。
