### 一个无头节点

`superone` 以 CLI 的形式发布,运行一个完全没有 Electron 的节点服务。它需要的运行时基础 —— 会话、文件系统、git、租约、spawn 环境、加密 —— 被抽成了双用途的包;每个 harness 也变成独立的包,只有启用时才依赖。节点从官方 npm 拉取 Claude 和 Codex,而不是把它们打包进去。

### 依赖桌面的工具会回家

节点没法给你显示一个浏览器。所以需要桌面的工具经由 host action 通道委派回来:节点发起调用,桌面执行,结果返回。远程会话上可以用完整的 SuperOne 工具面,而 host action 的授权是显式的,不是环境自带的。

### 事件,无损传输

`session.agent_event` 原样传输 harness 事件,于是远程会话的对话记录能与本地完全一致地重建。agent-event 映射器被专门抽成不依赖 Electron 的形式,正是为了让节点和桌面从同样的字节里推导出同样的东西。

### 同一份会话列表

节点上的会话、项目、技能和 MCP 服务,通过与本地相同的 environment API 访问,并带有分页和多层恢复,于是不稳的链路是降级而不是断裂。想要连的远程会自动连接并在唤醒时恢复;CLI 版本会与桌面比对,过旧的宿主会明确拒绝而不是行为异常。

### 怎么把 CLI 装过去

一条可选的升级通道通过 SSH 安装或更新节点 CLI;远程节点整体仍在实验设置开关之后。
