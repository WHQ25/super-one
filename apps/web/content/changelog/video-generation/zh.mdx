图像生成验证了形状。视频需要同样的形状,外加一个对"这次调用要花一美元、耗时两分钟"的回答。

### 四个后端,一张协议表

Sora、Veo、Seedance 以及 New API 兼容端点,作为视频 wire protocol 与图像协议一起声明在平台注册表里。同期还落地了原生的火山引擎 Ark 适配器,并把 Ark 的尺寸约束呈现在媒体 provider 列表中,于是模型会挑一个合法分辨率,而不是到 API 那里才失败。

### 花钱之前先确认

`media_generate_video` 在执行前会请求用户明确确认。工具块可展开,并在任务进行中报告实时状态 —— 一次两分钟的渲染不该看起来像一个卡住的回合。

### 片段落进图库

生成的视频与生成的图像并排渲染为图库卡片,作为输入的参考图也会显示在图库里 —— 于是"喂进去什么"和"产出什么"看得见地挨在一起。

### 每个 provider 一份说明

`read_manual` 增加了分 provider 的媒体章节,于是 agent 在调用某个后端之前先读到它的约束,而不是通过一个 400 才发现。
