内嵌浏览器让 agent 能读页面。WebMCP 让页面把键盘递给 agent。

### 先发现,再同意,然后记住

页面工具从文档中被发现,调用需要按来源(origin)取得同意,授权会被持久化 —— 于是一个站点你批准一次,而不是每次访问都批准。发现到的工具会在界面上呈现,页面工具调用的聊天行是专门设计过的,而不是渲染成通用的 MCP 输出。

### 信任按来源划分,而且是一道闸

站点信任决定会为该来源的整个页面工具面开闸或关闸。这比"逐次调用批准"刻意更严:能定义工具的页面也能改名和重新定义工具,所以有意义的信任单位是站点,不是单次调用。工具指纹用于捕捉那种"已批准的工具悄悄变成另一个"的情况。

### 它挂在浏览器上,不挂在 harness 上

因为 WebMCP 活在内嵌浏览器里,每个 harness 都能用上。页面只发布一次,Claude、Codex、Cursor、OpenCode、DeepSeek 以及任何 ACP agent 都能调用它。
