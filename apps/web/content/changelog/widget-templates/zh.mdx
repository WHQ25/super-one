一个渲染出好看仪表盘的 agent,产出的是一次性的东西。把它存下来,它才变成资产。

### 基于文件的模板仓库

渲染过的 widget 可以作为具名模板保存到磁盘。因为仓库就是普通文件,模板可以像项目里其他东西一样被备份、diff 和版本管理 —— 没有一个不透明的数据库需要你导出。

### 按名字重新渲染

`widget_show` 接受一个已保存的模板名,并用新数据渲染它。于是第二次想要那个布局时,你是"点名要",而不是再描述一遍。已保存的模板会出现在 agent 读取的 widget 指南里,这意味着模型会发现你已经有什么,而不是重新造一个。

### 保存是人的动作

保存 widget 的是你,不是 agent —— 保存控件就在渲染出来的 widget 上。一个模板之所以存在,是因为你判断它值得留下。
