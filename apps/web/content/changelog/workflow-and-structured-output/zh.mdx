当一个 agent 展开成多个并行 subagent 时,聊天界面以前会被一堆相互独立的卡片塞满。这次更新让多 agent 运行变得可读 —— 同样的用心也带到了结构化结果与 markdown 编辑器。

### 按阶段聚合的 Workflow

同一条 assistant 消息里的并行 subagent 与 Task 运行,现在聚合为单一 **Workflow** 块,并随运行进度按阶段分组。你能看清工作的形状 —— 哪些在展开、哪些在校验、哪些已完成 —— 而不是一摊扁平的卡片。Workflow 元信息与 agent 列表也会同步到手机,远程会话看到同样的视图。

### StructuredOutput 工具卡片

当 agent 返回结构化输出时,现在以一等的、工具样式的卡片呈现,而非裸文本 —— 一眼可读,与其他工具块保持一致。

### markdown 编辑器表格

markdown 编辑器新增 **表格** 斜杠命令,带网格选择器和行列编辑的右键菜单。你插入的链接现在会经过链接安全确认弹窗,任何跳转都先校验。
