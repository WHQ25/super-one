长会话以前是"一次性"的 —— 一旦在新对话里动了几下,你的临时改动、未完成实验、未提交 diff 就被锁在那个分支上。这次更新把会话面板重新设计为"可移植"的容器。

### 切换到 Worktree

在任意会话上右键选 **移到 Worktree**。SuperOne 会拉一个新的 git worktree,把未提交改动(包括 `git stash -u` 抓到的未跟踪文件)平滑迁移过去,并把 agent 的 `cwd` 重定向,所以下一轮对话无缝衔接。原分支保持干净。

Worktree 会话新增脏状态指示器,聊天状态栏的 worktree / 主仓库分支也合并到单一数据源,两个 pill 不再出现错位。

### 从任意消息分叉

在对话里悬停任一条消息,选 **从这里分叉**,就会打开一个新会话,历史截断到该处。两种风味:

- **本地分叉** —— 同 cwd 、另一条时间线,适合对同一个 prompt 探索不同答案。
- **Worktree 分叉** —— 独立 checkout,适合"换种思路再试一次",不影响当前工作区。

### 树形结构模糊搜索

Sidebar 文件选择器引入按目录分组的排序模糊匹配 —— 在 5000 文件的仓库里翻找也不会被扁平列表淹没。快捷键 <kbd>⌘P</kbd>。
