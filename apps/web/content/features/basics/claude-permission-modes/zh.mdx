## 它做什么

SuperOne 不会偷偷跑 shell、改文件、发请求。智能体第一次用到某个工具时,会弹出权限卡 —— 本次放行、本项目永久放行、全局永久放行,任选其一。

## 怎么工作

- 三档白名单:**session(本次)**、**project(本项目)**、**global(全局)**。后两者持久化,本次随关闭应用清空。
- 工具级精细控制。可以放行 `git status`,同时对 `rm -rf` 保持询问。
- 聊天框上方一个 kill switch,一键撤销所有权限。
- 活动面板保留带时间戳的完整审计记录,连同触发它的 prompt。

## 为什么有用

- 没有惊喜副作用。
- 跑别人写的 prompt 不用整个 yolo 信任。
- 合规审计变成一段可滚动的记录。

## 常见问题

**白名单存哪?** 项目级在 `.superone/permissions.json`(默认 gitignore),全局在用户配置。
