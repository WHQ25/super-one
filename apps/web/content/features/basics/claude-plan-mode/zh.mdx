## 它做什么

智能体动手之前,先给出一份逐步计划:要改哪些文件、顺序如何、原因是什么。你看一眼、调一下、点同意 —— 它才动手。

## 怎么工作

- 在聊天输入框里切换 planner 开关,任何请求都能走 plan 模式。
- 智能体会流式输出一份结构化计划:文件、命令、预期结果,按顺序排好。
- 一键同意、退回让它改,或者先批注:选中计划里任意一段留一张便签,每条评论有自己的荧光色。批注随同意一起回传,于是智能体收到的是贴在具体行上的异议。
- 计划随会话保留,后续随时回看、迭代。

## 什么时候用

- 第一次进入陌生代码库 —— 计划能告诉你智能体怎么理解项目结构。
- 涉及两个以上文件的重构。
- 任何破坏性操作:删除、数据库迁移、大范围重命名。

## 常见问题

**能默认开启计划模式吗?** 可以 —— 在设置里把会话或项目的默认设为 plan。

**计划会多花 token 吗?** 略微会。但复杂任务整体反而省 token,因为减少了返工。
