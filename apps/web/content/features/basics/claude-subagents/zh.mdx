## 它做什么

把代码审查、规划、研究等专才子代理叫进来,主对话不被淹没。子代理有自己的上下文,回到主对话时只交一份精炼摘要,不会把 token 噪声倒回去。

## 怎么工作

- 从内置子代理库里挑一个,或者自己定义。
- 每个子代理有自己的 system prompt、工具白名单、可选的模型。
- 前台跑(你等着)或者后台跑(完事推送你)。
- 结果以紧凑卡片形式落在主对话里,完整转录一键展开。

## 常见用法

- **Code reviewer** — 贴 diff,要一份第二意见。
- **Planner** — 真动手前先探几种方案。
- **Web researcher** — 大量抓取,只把摘要带回主线。
- **Test writer** — 补测试,不污染主对话的记忆。

## 常见问题

**子代理在哪配置?** 项目级在 `.superone/subagents/`,全局在设置里。都是 markdown + frontmatter 的纯文本。
