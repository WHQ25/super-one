## 它做什么

活动面板里的浏览器,同时也是 SuperOne MCP 面上的一组工具。每个 harness 都能用 —— Claude、Codex、Cursor、OpenCode、DeepSeek 以及任何 ACP agent —— 自己不必再带一个浏览器。

## 这些工具

- `browser_tabs` —— 打开、导航、刷新、关闭。localhost 有端口简写。
- `browser_snapshot` —— 把页面变成结构:带选择器的可交互元素、结构树、文本、console,或截图。区域可选,于是快照不会太大。
- `browser_act` —— 点击、悬停、输入、按键、滚动、拖拽、选择、上传。
- `browser_query` / `browser_wait_for` —— 定位你已经知道的目标,或者等待某个条件成立,而不是硬睡一段时间。
- `browser_evaluate` —— 当其他工具表达不了时,执行 JavaScript。
- `browser_network` / `browser_perf` —— 按需录制,不主动开启就什么都不抓。

## 是什么让它好用

- **稳定化的选择器。** 匹配出现歧义时会被报告出来,而不是悄悄选中第一个,于是 agent 知道自己需要再限定一下。
- **密文遮蔽。** 输入到密码类字段的值,在工具摘要里会被遮蔽。
- **紧凑输出。** 快照默认只取精简的区域集合,并可输出 TOON,避免一个大页面吃掉整个上下文窗口。

## 常见问题

**agent 的浏览器和我看到的是同一个吗?** 是。你看着的就是它在驱动的那些标签页,所以你可以边看边随时接手。
