## What it does

Slash commands, @-mentions, file drops, image paste, IME-aware Enter. The chat input you only notice when it's missing somewhere else.

## How it works

- **Slash menu** — type `/` for fuzzy-searched commands: `/plan`, `/clear`, `/model`, custom skills, and anything you've installed.
- **Mentions** — `@` opens a picker for files, sessions, and known artifacts.
- **File drop & paste** — drag folders, paste screenshots, attach binaries. The agent gets a real attachment, not a stringified blob.
- **IME-safe Enter** — Chinese/Japanese/Korean composition never triggers send mid-character.
- **Markdown preview** — code fences, inline code, links — rendered as you type.

## Shortcuts

- <kbd>↵</kbd> — send
- <kbd>⇧</kbd> <kbd>↵</kbd> — newline
- <kbd>/</kbd> — slash menu
- <kbd>@</kbd> — mention picker

## FAQ

**Can I disable Enter-to-send?** Yes, in settings — switch to <kbd>⌘</kbd> <kbd>↵</kbd> for send.
