## 它做什么

斜杠命令、@ 提及、拖拽文件、粘贴图片、输入法感知的回车 —— 这种小细节,你只在别处缺它的时候才会注意到。

## 怎么工作

- **斜杠菜单** — 输入 `/` 模糊搜索所有命令:`/plan`、`/clear`、`/model`、自定义 skill,以及你安装的一切。
- **提及** — `@` 打开选择器:文件、会话、已知工件都能挑,还有内置能力 —— 某个协作者、要授予 Computer Use 的桌面应用、浏览器、widget,或者 `@debug`。
- **拖拽与粘贴** — 拖文件夹、粘截图、附二进制。智能体拿到的是真附件,不是字符串化的乱码。
- **IME 安全回车** — 中日韩输入法 composition 中,回车不会误发送半个字。
- **Markdown 预览** — 代码块、行内代码、链接,边打边渲。

## 快捷键

- <kbd>↵</kbd> — 发送
- <kbd>⇧</kbd> <kbd>↵</kbd> 或 <kbd>⌥</kbd> <kbd>↵</kbd> — 换行
- <kbd>/</kbd> — 斜杠菜单
- <kbd>@</kbd> — 提及选择器

## 常见问题

**怎么写多行消息?** <kbd>⇧</kbd> <kbd>↵</kbd> 或 <kbd>⌥</kbd> <kbd>↵</kbd> 插入换行。单独的 <kbd>↵</kbd> 一定是发送 —— 并且在输入法 composition 期间绝不会打断半个字。
