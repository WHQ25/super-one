## 它做什么

handoff 启动一个接手的同级会话。与 spawn 不同,新会话不是在为旧会话打工 —— 它继承了任务,并继续做下去。

## 怎么工作

- 交接带走的是一份持久的 Markdown 文档,不是一段口头总结。计划、约束和文件上下文都被写下来,随任务一起走。
- 同级会话可以跑在任意引擎上。当剩下的工作更适合 Codex 时把它从 Claude 交过去,或者转到一个具备当前引擎所缺能力的 harness。
- 对话记忆留在原会话。转移的只有任务说明,这是刻意的 —— 一个上下文干净的新会话,往往正是交接的目的。
- 原会话保持打开。交接之前它做了什么,你随时可以回去读。

## 什么时候用

- 任务改变了形态,当前会话的上下文如今大部分是噪音。
- 剩下的工作更适合另一套引擎。
- 一个长会话接近上下文上限,而你宁愿重述目标,也不想 compact 它。

## 常见问题

**这和 spawn 有什么区别?** spawn 让父会话继续主导并接收汇报。handoff 转移的是归属 —— 交接之后,干活的是那个同级会话。
