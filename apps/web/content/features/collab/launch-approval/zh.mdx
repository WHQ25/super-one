## 它做什么

agent 不能自己启动协作者。它提出请求,你读完,然后放行或拒绝。

## 为什么这个请求是可读的

启动任务渲染成 markdown 气泡,不是原始的工具载荷。在任何东西开始之前,你看到的是协作者将要收到的真实任务说明 —— 目标、约束、工作目录。启动摘要与完整任务是分开保存的,于是侧栏可以显示一行简述,而气泡里承载全部内容。

## 默认自治

被批准的子会话以自治权限模式启动。这是刻意的:一个每用一个工具就停下来等批准的子会话,把一个需要盯着的会话变成了两个,与委派的初衷正好相反。你只在你还能判断的那个时点批准一次委派。

## 常见问题

**我可以拒绝并让父会话继续吗?** 可以。拒绝结束的是这次启动,不是父会话的回合 —— agent 收到拒绝后,会继续做它自己能做的部分。
