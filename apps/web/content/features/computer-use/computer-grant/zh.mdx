## 它做什么

Computer Use 一次只授权一个应用。你把某个具体应用交给 agent,它拿不到你的屏幕。

## 怎么工作

- **提及即授权。** 在聊天输入框 `@` 提及一个桌面应用,即可把它的控制权交给当前会话。授权界面显示应用的真实图标,于是你在授权什么毫不含糊。
- **常用的可以始终允许。** 你经常驱动的应用可以设为长期许可;其余的每个会话都会问一次。
- **第一次有引导。** 首次授权时,一个拖拽浮层带你走完权限步骤,而不是把你丢进一个没有上下文的系统设置面板。
- **按会话,而不是永久按应用。** 授权属于提出请求的那个会话。会话关闭,授权结束。

## agent 看得到什么

只有你授权的那个应用。它拿到的目录被压缩为"正在运行且可控"的清单,而不是磁盘上每个 bundle;捕获也限定在该应用的窗口范围内。

## 常见问题

**能收回吗?** 能 —— 权限可以在设置里撤销,包括那些"始终允许"的条目。

**agent 看得到其他窗口吗?** 看不到。捕获限定在被授权应用的窗口内;出现在它之上的模态框会被识别,而不是被穿透点击。
