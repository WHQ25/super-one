## 它做什么

用你的 Anthropic API key 跑 Claude,或者用 OAuth 登录、使用你已有的套餐。

## 怎么工作

- **OAuth** 通过内嵌浏览器登录,令牌存进 SuperOne 的凭据存储。用量与剩余额度从账号读取,于是应用能直接告诉你处在什么位置,而不是从 token 数去猜。
- **API key** 是另一条路,适合你更愿意按 token 付费、或使用一把不绑定个人登录的密钥时。
- 模型目录按你账号实际拥有的东西过滤。套餐里没有的模型就不显示 —— 这份列表是账号的答案,不是随版本发出去的一张表。
- 凭据只存一次,每个会话都够得着,于是换项目或换 harness 不意味着要重新登录一遍。

## 为什么凭据存储是共享的

provider 密钥是关于你的事实,不是关于某个会话的事实。按会话存意味着不断重新输入,而且没有一个统一的地方去吊销它。统一存储也意味着一个会话派生出另一个 harness 上的子会话时,不必把凭据传过去。

## 常见问题

**两种可以都配吗?** 可以 —— 用哪一种是按会话选的。

**密钥存在哪?** 存在应用的凭据存储里,不在你仓库的配置文件里。
