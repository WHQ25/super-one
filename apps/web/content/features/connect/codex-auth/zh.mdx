## 它做什么

Codex 会话有三种认证方式 —— `auto`、ChatGPT 登录、API key —— 你随时可以切换。

## 三种方式

- **Auto** 挑选任何可用的凭据,当你两种都有、且不在意用哪一种时,这是正确的默认值。
- **ChatGPT 登录** 使用你已有的订阅。登录在内嵌浏览器里完成,令牌落进共享凭据存储。
- **API key** 用一把 OpenAI 密钥按 token 计费。

## 切换

方式是按会话的设置,项目做到一半也能改。切换不会重置线程 —— 下一轮用新凭据发出去,对话继续。

用量与速率限制按模型跟踪,于是订阅撞到上限时你看得见,而不是从一次失败里推断出来。

## 常见问题

**模型列表会随认证方式变吗?** 会 —— 目录来自当前生效凭据背后的那个账号。

**`auto` 有什么聪明之处吗?** 没有。它挑现成的那个;它不会在一轮中途做故障转移。
