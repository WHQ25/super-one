## 它做什么

relay 是一个由 Durable Object 支撑的 Cloudflare Worker。你可以在自己的 Cloudflare 账号上跑它,而不用托管版。

## 怎么工作

- 每个房间一个 Durable Object,持有连接状态与挂在其上的设备的事件缓冲。Durable Object 在这里形状正好,因为一个房间需要一个一致的地方来给事件定序 —— 另一条路是跨边缘节点去调和顺序。
- 缓冲的事件按设备 ACK 释放,于是掉线的设备拿到的是积压,而不是一个缺口。
- 部署就是对你的账号执行 `wrangler deploy`;之后把桌面端指向你的 Worker URL。
- relay 走自己的 semver tag 发布,与桌面应用的发布列车分开,因为两者不必同步移动。

## 为什么值得提供

relay 从来看不到明文,于是自托管不是一次安全升级 —— 它是可用性与管辖权上的选择。有些团队需要流量经过自己掌控的基础设施,即便内容本来就不可读,这依然是正当需求。能说一句「自己跑,方法在这」,比为此争论便宜。

## 常见问题

**自托管会削弱什么吗?** 不会;加密不变。你换掉的是由谁来运营这个路由器。

**成本多少?** 就是你自己账号上的 Workers 与 Durable Objects 计费 —— relay 每条消息的计算量非常小。
