## 它做什么

对话里引用到的文件以 chip 形式出现,而不是一串裸路径,并且 chip 可以点开。

## 怎么工作

- chip 携带的是文件的身份而不只是名字,于是不同包里两个都叫 `index.ts` 的文件仍然可分辨。
- 点击它会在对话旁边的预览面板里打开。
- chip 也可以在浏览器面板里打开该文件,用于查看渲染后的 HTML 或 Markdown 产物,而不是它的源码。
- chip 在你写的内容和 agent 回复的内容里都会出现,于是 agent 动过的文件,从提到它的那条消息就能到达。

## 为什么不直接写路径

正文里的路径是需要你复制、粘贴、再定位的东西。chip 就是那个文件 —— 从提到它的那句话到它的内容只需一次点击,不必离开对话,也不必推断这条路径是相对于哪里的。

## 常见问题

**chip 扛得住复制粘贴吗?** 扛得住 —— 它通过不可见标记往返,于是把消息粘贴到别处时引用仍然完整。
