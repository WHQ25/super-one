## 它做什么

回复在流式输出的同时就按 Markdown 渲染 —— 带高亮的代码块、列表、链接、表格、公式与图表 —— 而不是先显示成纯文本、等回合结束才排版。

## 流式渲染而不重排

增量渲染比一次性渲染难,因为一个只到了一半的代码块还不是合法的 Markdown。渲染器依据块完成信号工作,而不是每来一个 token 就重新解析整条消息,于是一条长回复不会每落一个字符就从头重排一次。

## 它能渲染什么

- 带语法高亮的代码块。
- 行内与块级数学公式。
- Mermaid 图表,配色跟随应用主题。
- 表格、任务列表、脚注,以及 GitHub 风格 Markdown 的其余部分。
- 外部链接前的 favicon,于是不用悬停就能认出链接指向哪里。

## 保持可见

回合折叠时,它渲染出的 markdown 和 widget 仍然可见。折叠隐藏的是过程 —— 工具调用和中间步骤 —— 不是答案。

## 常见问题

**图表能交互吗?** Mermaid 图表是原生渲染并跟随主题;可交互的界面是 widget,它有自己的工具。
