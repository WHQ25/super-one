## 它做什么

`@` 打开一个选择器,列出你想让 agent 去看的东西:文件、会话、工件 —— 以及一组内置能力。

## 内置提及

除了文件和会话,`@` 还能直接够到这些能力:

- **某个协作者**,用于点名跟某个子会话或已连接的会话说话。
- **某个桌面应用**,提及即把它的 Computer Use 控制权授予当前会话。
- **浏览器**,把 agent 指向当前打开的页面。
- **某个 widget**,要一个渲染出来的界面而不是一段文字。
- **`@debug`**,它会先问你出了什么问题,而不是让 agent 直接开始猜。

## chip 为什么能扛住复制粘贴

一次提及会变成一个 chip,而 chip 携带不可见的零宽标记。复制一条消息粘贴到别处,它会还原成 chip 而不是退化为纯文本,于是 agent 仍然知道你指的是哪个文件,而不是收到一个需要它猜的裸名字。

## 常见问题

**提及一个文件会把内容发过去吗?** 发的是引用。agent 需要时才去读文件,于是一个大文件在真正相关之前不会挤进 prompt。
