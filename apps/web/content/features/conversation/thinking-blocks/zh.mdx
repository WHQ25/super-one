## 它做什么

推理过程显示为可折叠的块:默认折起,让结论在前;想看它是怎么得出来的时候再展开。

## 怎么工作

- **连续的推理会被合并。** 引擎是分片吐出推理内容的,把每一片渲染成独立的块会得到一摞几乎空的卡片。同一段思考会被合并成一个块。
- **时长被持久化。** agent 想了多久与这个块一起记录下来,于是重新打开会话时它仍在,而不是归零。
- **不同引擎,同一形态。** Claude 的 thinking 与 Codex 的 reasoning item 渲染进同一种块,于是无论哪套引擎产生的,记录读起来都一致。

## 为什么默认折起

推理内容在结果出乎意料时很有用,其余时候是噪音。默认折叠是为常见情况优化,同时不丢弃审计线索 —— 内容就在那儿,点一下即可展开,并且随会话持久保存。

## 常见问题

**effort 会影响它吗?** 更高的 effort 会产生更多推理,块也就更长。effort 本身与模型一起,按会话选择。
