## 它做什么

Android 模拟器与真机会被发现进与 iOS 模拟器同一份设备目录,通过同一道 agent 接缝驱动,并实时流进面板。

## 怎么工作

- **发现进共享目录。** 模拟器和已连接的手机与其他设备并列出现,于是 agent 请求的是"一台设备",而不是"一个平台"。
- **一个连接服务所有观看者。** 到设备的单一连接同时服务面板、浮动预览和 agent,而不是各开各的流去抢同一个 socket。
- **按你会用的方式命名。** 真机上报的型号是零件号;目录会解析出市场名,于是你挑的是一台你认得出的手机。
- **中立的画面与输入类型。** 画面和输入模型与平台无关,这正是同一套工具能同时驱动 iOS 模拟器和 Android 手机、而 agent 不必按平台分支的原因。

## 生命周期

为某个会话启动的模拟器会随应用一起关闭,于是你退出之后,不会有一个被遗忘的模拟器继续消耗这台机器。

## 常见问题

**一个会话能同时持有两台设备吗?** 可以。每个设备标签有自己的身份,agent 会指明某次调用是给哪一台的。
