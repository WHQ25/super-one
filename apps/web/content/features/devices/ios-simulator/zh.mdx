## 它做什么

在对话旁边预览正在运行的 iOS 模拟器,并让 agent 读取和操作它 —— 优先用结构,只在结构耗尽的地方才用像素。

## 怎么工作

- **优先语义树。** 助手读取模拟器的辅助功能树,于是 agent 查询的是带标签的元素,而不是从截图里猜坐标。
- **识别到的文字并入这棵树。** 屏幕上找到的文字会作为普通 UI 树的一部分呈现,而不是另外给一份 OCR 结果,于是只有一种结构需要查询,不是两种。
- **像素作为兜底。** 应用什么都没描述的区域,才从画面帧里读 —— 补上缺口,而不是掩盖它。

## 快照为什么带指纹

快照的身份是结构树与画面帧共同构成的指纹。两者中任何一个单独看都可能过期而另一个已经变了:一个视图可以在不改变辅助功能树的情况下重绘,一棵树也可以比像素早一帧更新。元素引用会 pin 到它来源的那个快照上,于是对过期引用动手会明确失败,而不是点中此刻恰好占据那个位置的东西。

## 预览就是取景器

浮在聊天之上的预览,显示的就是 agent 正在操作的那个表面。你在看的和它在驱动的是同一件东西。

## 常见问题

**支持旋转吗?** 支持 —— 旋转会被处理,结构树与画面帧的宽高随之跟上。
