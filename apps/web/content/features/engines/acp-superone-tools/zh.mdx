## 它做什么

每个 ACP 会话都会被宿主挂上 SuperOne 自己的 MCP 服务 —— 内嵌浏览器、设备控制、电脑操作、生图生视频、widget 与小程序都在其中。

## 怎么工作

宿主在会话创建时挂载该服务,而不是要求 agent 去配置它。从 agent 那一侧看,这些就是普通的 MCP 工具;它不需要知道这些属于宿主,也不需要在谁的配置文件里有一条记录才够得着。

这正是「接协议而不接厂商」的意义所在。一个自己的 CLI 从未内置浏览器的 ACP agent,在这里能驱动浏览器,因为浏览器不是 agent 的功能 —— 它是宿主的,而宿主是每个 harness 的共同之处。

## 目前还没覆盖的

把**你自己的** MCP 服务挂到 ACP 会话上是另一个缺口:宿主的服务是自动挂上的,但用户配置的服务在 ACP 这边还没有接通。

## 常见问题

**这意味着 ACP agent 能控制我的手机吗?** 它可以调用设备工具,但要经过其他每个 harness 同样要走的授权与审批流程。
