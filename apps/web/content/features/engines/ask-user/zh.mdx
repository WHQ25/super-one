## 它做什么

当 agent 需要你做决定时,它会带着结构化选项来问,而不是丢下一段文字然后干等。

## 怎么工作

- 问题渲染成一张卡片,选项是按钮,于是回答是点一下,而不是敲一句话再让 agent 去解析。
- 多个问题可以一起到来,各带各的选项;选项之间不互斥时支持多选。
- 选项可以带预览,于是一个关于两种布局的问题会把两种都展示出来,而不是用文字描述。
- 你的选择会就地回显在结果里,于是记录下来的是你实际选了什么,而不只是"你回答了"。

## 为什么结构化优于自由文本

开放式提问招来的是一个 agent 必须去理解的答案,而误解正是在"理解"这一步发生的。把它确实能据以行动的选项摆出来,就去掉了这一步 —— 并且逼着 agent 在发问之前先想清楚备选项到底有哪些。

## 常见问题

**我能回答选项之外的内容吗?** 能 —— 当所有选项都不对时,始终有一条自由输入的通道。
