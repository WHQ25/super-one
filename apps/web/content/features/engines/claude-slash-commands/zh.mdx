## 它做什么

Claude 自己的斜杠命令与其他一切出现在同一个 `/` 菜单里,还包括你已安装的 skill 提供的命令。

## 怎么工作

- 内置命令、项目命令和 skill 提供的命令一起被搜索,于是你输入的是"你想要什么",而不是"它来自哪个来源"。
- 只在终端里才讲得通的命令会从宿主菜单里隐藏,而不是显示出来、选中后才失败。
- 会产出报告的命令,其输出保留在对话记录里,于是回合结束后结果仍然可读。
- Skills 按用户或按项目管理,于是一个项目可以带自己的命令,而不污染其他每个项目。

## 常见问题

**我的 skill 在别的引擎上也能用吗?** Skill 是 Claude 的概念,但 SuperOne 自己的宿主命令在所有引擎上都能用,其他 harness 也会把各自的原生命令贡献到同一个菜单里。
