## 它做什么

Cursor 的权限模式与沙盒开关的读法,与其他每套引擎一致,于是切换 harness 不意味着要重新学一遍应用被允许做什么。

## 映射

SuperOne 的共享权限词汇诚实地映射到 Cursor 上,而不是近似地映射:

- **Plan** 变成 Cursor 的 `plan` 模式,自动评审关闭 —— agent 推理并提出方案,但不编辑。
- **Agent** 与 **Auto** 都变成 `agent` 模式,自动评审开启。
- **Bypass permissions** 仍是 `agent` 模式,但关掉自动评审,这才是诚实的读法:你要的是别打断你,不是换一种执行模式。

沙盒是**独立的**开关。它没有被折进权限模式里,因为「沙盒内的完全访问」与「无沙盒的 plan」都有意义,而一旦把两个旋钮合并,两者都表达不出来。

## 为什么要分开

把沙盒并进模式是很诱人的简化,也正是让应用开始说谎的那个简化。模式回答的是「它多久问我一次」;沙盒回答的是「它不问的时候能碰到什么」。合并意味着这两个问题里必有一个要靠猜来回答。

## 常见问题

**plan 模式下还能读文件吗?** 能。plan 限制的是写,不是读。
