## 它做什么

OpenCode 自带 agent 与原生命令。两者都被接在共享的会话生命周期上呈现,而不是被重新实现一遍。

## 怎么工作

- agent 名册来自 OpenCode 服务端,于是你在自己配置里定义的 agent 会出现在选择器里,SuperOne 不需要预先知道它们的名字。
- 原生命令 —— 包括写入项目 agent 指令的 `init` —— 派发给服务端,其输出以普通一轮的形式落进对话记录。
- 选中的 agent 是按会话的,与模型一同保存,于是一个钉在评审 agent 上的会话重启后仍在那个 agent 上。
- todos 与 subagent 在这里都受支持,这意味着一次长时间的 OpenCode 运行,渲染出的任务清单与嵌套 Task 块与在 Claude 上一致。

## 差异在哪

OpenCode 只接受单个 `directory` 而非一个列表,于是它的会话不提供「附加目录」控件。这是声明在 harness 上的能力,不是调用点的分支 —— 控件是消失,而不是在被用到时失败。

## 常见问题

**`/init` 会覆盖已有的指令文件吗?** 那是 OpenCode 自己的行为;SuperOne 原样派发该命令。
