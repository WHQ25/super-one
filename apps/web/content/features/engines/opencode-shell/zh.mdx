## 它做什么

在 OpenCode 会话内运行 shell 命令,并把该会话以公开链接的形式分享或取消分享。

## Shell 模式

以 `!` 开头的消息是 shell 命令,不是提示词。它经由 OpenCode 自己的 shell 路径运行,使用该会话的模型与 agent,输出落进对话记录里,模型在下一轮就能读到。shell 消息上的附件会被拒绝 —— 图片作为命令没有意义,而静默丢掉它比拒绝更糟。

## 分享

`/share` 发布会话并返回链接;`/unshare` 再把公开访问撤掉。回复里明确写着这个链接是公开的,因为一个读起来像私有的分享链接,是那种只会犯一次的错误。

## 为什么要走会话

打进会话里的 shell 命令,与打进旁边终端里的不是一回事:输出成为对话的一部分,于是下一轮已经知道发生了什么。这就是 `!` 待在这里而不是待在独立面板里的全部理由。

## 常见问题

**`!` 遵守会话的权限模式吗?** 它走 OpenCode 自己的执行路径,受该路径所强制的规则约束。
