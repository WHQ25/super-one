## 它做什么

Claude 在工作过程中维护一份任务清单,把条目从待办改成进行中再改成完成;SuperOne 把它渲染成一份实时清单,而不是一段需要你自己去读的工具输出。

## 为什么值得呈现出来

否则一个长回合是不透明的:你看得到 agent 在忙,但看不到它认为还剩什么。这份清单让计划和进度同时可见 —— 这正是让你能在计划本身就不对时提前打断,而不是等它执行完的原因。

## 怎么工作

- 弹窗显示当前清单,状态栏不打开弹窗也能反映进度。
- 条目随 agent 的工作就地更新,于是这份清单是状态,而不是状态变更的流水账。
- 清单属于该回合自身的推理;你读它并据此引导,而不是直接编辑它。

## 常见问题

**别的引擎有这个吗?** 任务跟踪是 Claude 的能力。引擎不具备时,应用把这一点声明为数据,而不是渲染一个空清单。
