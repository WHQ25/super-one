## 它做什么

指着页面上的某个东西,把它交给 agent —— 点选一个元素附到聊天输入框,或者把图片直接拖进对话。

## 怎么工作

- 元素点选会把指向该元素的结构化引用放进输入框,于是下一条消息说的「这个按钮」,是 agent 可以据以行动的说法,而不是你需要描述出来的说法。
- 图片从页面里拖进对话成为附件;它们以普通图片内容落地,任何接受图片的 harness 都读得到。
- 从页面复制图片走的是浏览器自己的剪贴板路径,这里需要小心处理焦点 —— WebView 里的右键复制,并不是宿主窗口以为的那个事件。

## 为什么指比描述好

「工具栏里第三个按钮」是一句模型必须从快照里重新推导的话,而且可能推错。你点出来的引用,从构造上就没有歧义。这和「堆栈比 bug 报告好」是同一个道理:你本来就确切知道自己在哪,代价只在于把这个事实完整地传过去。

## 常见问题

**agent 之后还会重新截快照吗?** 可以 —— 引用指向页面内部,而页面还在那里。
