## 它做什么

SuperOne 的电脑操作捕获的是一个**窗口**,而不是屏幕 —— agent 看的是它正在处理的那个应用,并且只看那个应用。

## 这个区别为什么重要

屏幕捕获把你面前的一切都交给模型:另一个开着收件箱的窗口、刚弹出来的通知、你第二块显示器上的任何东西。窗口捕获才是你说「看看这个应用」时真正想要的范围。收窄捕获不是限制;它就是这个功能本身。

## 怎么工作

- 捕获按窗口划定范围,模态安全跨窗口成立 —— 另一个应用里的模态框不会变成 agent 的问题,而目标窗口里的模态框不会被漏掉。
- 辅助功能的瞬态根节点被纳入进来,这才让菜单保持可读。下拉菜单或右键菜单在辅助功能树里并不是窗口的子节点;一个只走窗口自身子树的捕获,会把一个展开的菜单显示成一块空白矩形。
- 结果是 agent 读取的语义树,而不只是像素 —— 于是一个按钮是一个带标签的按钮,而不是一片需要它去识别的区域。

## 常见问题

**agent 能操作它没有捕获的窗口吗?** 操作与捕获一样,限定在被授权的那个窗口上。
