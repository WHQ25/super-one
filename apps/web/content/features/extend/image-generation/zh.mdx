## 它做什么

`media_generate_image` 对每个 harness 开放,于是任何引擎都能生成或编辑图像,哪怕它自己的 CLI 从未内置过这项能力。

## 怎么工作

- provider 从模型目录读取,而不是一份硬编码列表,于是你账号新拿到的模型不必等应用更新就会出现。
- 结果汇集到**该轮末尾的图库卡片**里,而不是一张一张打断对话记录。一轮产出六个变体,读起来就是六个变体,而不是六条你要滚过去的独立消息。
- 宿主会自动内联展示生成的媒体。agent 若再用 Markdown 把结果嵌一遍,就是重复了 —— 图片已经在那儿了。

## 值得知道的 provider 怪癖

不是每个能生图的 provider 都能改图。火山引擎的图生图端点返回 404,这是 provider 的事实,而不是配置错误 —— 有用的反应是给编辑换一个 provider,而不是反复去查凭据。

## 常见问题

**文件放在哪?** 放进该会话的媒体存储,从对话记录里引用。

**小程序能调用它吗?** 能 —— 它就是同一个面上的普通工具。
