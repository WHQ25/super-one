## 它做什么

给会话挂上 Model Context Protocol 服务,支持 MCP 的每套引擎都能调用它们 —— 服务只配置一次,而不是每个 harness 配一次。

## 怎么工作

- 服务在 SuperOne 里配置,在会话创建时挂载,于是你新增的服务对 Claude 会话与 Codex 会话都可用,不必描述两遍。
- 传输方式由服务自己决定:本地进程用 stdio,远端用 HTTP 或 SSE;服务需要 OAuth 时,授权在内嵌浏览器里完成。
- MCP 支持在 `HARNESS_CAPABILITIES` 里按 harness 声明。某套引擎接不了用户服务时,挂载控件对它直接不出现,而不是在被用到时失败。
- 工具结果回来的是一个 envelope,而不是纯文本,于是结构化内容、图片与错误都能完整地进到对话记录里。

## 宿主自己的服务在哪一层

SuperOne 也跑着自己的 MCP 服务 —— 本文档别处提到的浏览器、设备、生图生视频、widget 与小程序,就是这个服务的工具。它是自动挂上的;你的服务与它并列。

## 常见问题

**MCP 工具走权限提示吗?** 走,与原生工具同一条路径,并且可以按工具自动放行。

**服务会按会话重启吗?** stdio 服务是一个进程;生命周期跟随挂载它的那些会话。
