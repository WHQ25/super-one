## 它做什么

Skill 是预先烘焙好的 agent 工作流:一个装着指令的目录,agent 按需加载,用 `/skill-name` 调用。

## 怎么工作

- 一个 skill 是一个目录,里面有 `SKILL.md`,其 frontmatter 带着名字与一句话描述。agent 判断某个 skill 是否适用时,匹配的就是这句描述。
- 在输入框里打 `/` 会列出本项目以及你用户级 skill 目录里可用的 skill,用的是列出原生命令的同一个选择器。
- 调用一个 skill 会把它的指令加载进这一轮 —— 对这类任务,agent 按这份指令行事,而不是按它的默认做法。
- 有些 skill 改为在 subagent 里运行,返回的是做完的结果而不是指令。

## 为什么是目录而不是一段提示词

skill 的意义在于它能活过这次会话。你粘贴的提示词随上下文一起消失;而 skill 是仓库里的一个文件,像代码一样被评审,下一次会话 —— 或者下一个人 —— 拿到的是同一套流程。这也是 skill 默认放在项目里的原因:一份发布检查清单属于这次发布,而不属于写它的那个人。

## 常见问题

**Skill 在其他引擎上能用吗?** Skill 是 Claude 的机制。其他引擎有各自的命令面,SuperOne 原生地把它们呈现出来。
