## 它做什么

`widget_show` 附带六个指南模块,agent 可以在动笔之前加载 —— 每个模块是某一类视觉的「家族风格」,于是产出看起来是有意为之,而不是临时发挥。

## 六个模块

- **`diagram`** —— 架构图、流程图、时序图。
- **`mockup`** —— 界面布局与组件稿。
- **`interactive`** —— 让读者动手操作的讲解件。
- **`chart`** —— 数据可视化。
- **`art`** —— 插画与装饰性作品。
- **`native`** —— 与宿主应用自身组件和 token 一致的界面。

## 为什么是模块而不是一大段提示词

图表与插画想要的建议是相反的。折进同一个指令块里,一方的指导会稀释另一方,模型会把它们平均成一个两边都不像的东西。只加载适用的那个模块,能让每一套规则保持锋利 —— 也让花在指导上的 token 与所画的东西成比例。

`native` 是其中有意思的那个:正是它让 agent 写出的 widget 待在应用里而不像个外来物,因为它是对着应用自身界面所用的同一套 token 写的。

## 常见问题

**可以同时加载多个模块吗?** 可以 —— 一个 native 风格面板里的图表就是合理的组合。
