## 它做什么

`widget_show` 是 agent 调用的一个 MCP 工具,用来在聊天里内联渲染视觉内容 —— SVG 图、交互式 HTML 组件、图表 —— 而不是用文字描述它。

## 怎么工作

- agent 传入标记;宿主把它渲染在对话记录内的沙盒 iframe 里,尺寸适配对话。
- widget 是可交互的:agent 接好的控件可以回调进会话,于是 widget 是你可以用的界面,而不是你看的一张图。
- 值得留下的 widget 可以存为模板,之后列出来复用,于是你喜欢的那个仪表盘不必重新描述一遍。
- mermaid 是例外:```mermaid 围栏块由宿主原生渲染,于是画一张普通的图根本不需要这个工具。

## 为什么要沙盒

widget 是模型写出来的标记,这意味着它从构造上就该被当作不可信 —— 一个够得着宿主页面的 iframe,就是一条直接通出对话记录的逃生口。正是沙盒让「让模型写界面」成为一个合理的主意,而不是一个鲁莽的主意。

## 常见问题

**agent 什么时候该用 widget 而不是表格?** 内容是视觉的、数据密集的或可交互的时候。一个短列表用 Markdown 更好。
