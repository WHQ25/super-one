## What it does

Choose how the window itself looks and how many of them you want.

## Liquid Glass

An optional translucent treatment: frosted, layered surfaces backed by native window vibrancy. It is gated separately from the theme, so leaving it off keeps the classic opaque look unchanged. Available on macOS and on Windows 11.

## Native chrome per platform

Window chrome is native rather than emulated. On Windows the caption buttons are drawn by the system, which means the app has to report its own colour to them — the overlay follows the sidebar rather than the page background, so the buttons sit on the surface actually behind them.

## More than one window

- **Mini window** — drag a session out of the sidebar and it opens in its own small window, with the drag preview following your cursor across the boundary. Folding is reversible, so a folded mini window comes back the way it went.
- **Mosaic** — or keep one window and split it, dropping sessions into a binary split tree with resizable dividers.

## FAQ

**Does Liquid Glass affect performance?** It uses native vibrancy rather than a CSS blur stack, so the cost is the compositor's, not the renderer's.
