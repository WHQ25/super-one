## 它做什么

选择窗口本身长什么样,以及你想要几个窗口。

## Liquid Glass

一层可选的半透明处理:磨砂、分层的界面,由原生窗口 vibrancy 支撑。它与主题分开门控,所以不开启时经典的不透明外观保持原样。macOS 与 Windows 11 均可用。

## 每个平台的原生窗口装饰

窗口装饰是原生的,不是模拟的。在 Windows 上标题栏按钮由系统绘制,这意味着应用必须把自己的颜色回报给它们 —— overlay 跟随侧栏而不是页面背景,于是按钮落在真正位于它们身后的那个表面上。

## 不止一个窗口

- **迷你窗口** —— 把会话从侧栏拖出来,它会以独立小窗口打开,拖拽预览跨越窗口边界跟着光标走。折叠是可逆的,折起来的迷你窗口会按原样回来。
- **马赛克** —— 或者只保留一个窗口然后分屏,把会话放进带可拖拽分隔线的二叉分割树里。

## 常见问题

**Liquid Glass 影响性能吗?** 它用的是原生 vibrancy 而不是一层 CSS 模糊叠加,所以开销在合成器那边,不在渲染进程。
