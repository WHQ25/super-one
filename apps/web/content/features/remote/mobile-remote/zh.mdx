## 它做什么

在公交车上接着上一个会话,在厨房里批一个工具权限,任务跑完手机会响。手机就是桌面 SuperOne 的完整遥控器。

## 怎么工作

- Cloudflare Workers relay(你也可以自己托管)在桌面和手机之间架一条端到端加密的通道。
- 移动端一台只订一个 active 会话;turn 实时流过来。
- 计划审批、权限弹窗、斜杠命令,移动端都能用。
- 后台任务完成或者有审批等你时,推送通知会响。

## 自托管

- Relay 就是一个 Cloudflare Worker + Durable Object。准备一个 Cloudflare 账号,跑 `wrangler deploy`,把设备指向你自己的域名。
- 不依赖第三方存储 —— relay 只缓冲会话最近的事件用于重放。

## 常见问题

**手机会话中途掉线怎么办?** Relay 会缓冲事件,网恢复后从你上次 ack 的位置按顺序重放。
