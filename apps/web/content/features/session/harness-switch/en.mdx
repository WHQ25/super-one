## Why two harnesses?

Different models have different strengths. Claude is sharper on long reasoning and large refactors. Codex is faster on focused edits and quick scripts. Instead of forcing you to pick once, SuperOne keeps both within arm's reach.

## How it works

- Each session has its own engine, model, and effort level — chosen at creation or switched mid-task.
- Brand hue follows the active harness (warm orange for Claude, cool green for Codex), so you always know who is talking.
- Memory, slash commands, and tool permissions stay independent per harness.

## Shortcuts

- <kbd>⌘</kbd> <kbd>N</kbd> — new Claude session
- <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>N</kbd> — new Codex session
- <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>H</kbd> — switch the active session's harness

## FAQ

**Do I need both API keys?** No. You can run only Claude, only Codex, or both. The other engine simply stays disabled.

**Can a session hand off mid-task?** Yes — the plan and file context transfer to a new session, but conversation memory stays with the original.
