## 为什么不止一套引擎?

不同模型擅长的事情不一样。Claude 在长推理、大型重构上更稳;Codex 在小步快改、脚本类任务上更快;Cursor、OpenCode、DeepSeek 以及任何兼容 ACP 的 agent 各有各的长处。SuperOne 不强迫你选一个,而是把它们都摆在桌面上。

## 怎么用

- 每个会话都有自己的引擎、模型和 effort,创建时选,中途也能切。
- 应用主题色会跟随当前引擎(Claude 暖橙、Codex 蓝、OpenCode 绿、Cursor 蓝灰、DeepSeek 蓝紫、ACP 上的 Grok 紫),一眼能分清是谁在说话。
- 记忆、斜杠命令、工具权限对每套引擎各自独立。
- 每套引擎都继承同一份 SuperOne 工具面 —— 浏览器、设备、Computer Use、媒体生成 —— 无论它自己的 CLI 有没有这些。

## 快捷键

- <kbd>⌘</kbd> <kbd>N</kbd> — 新建会话
- <kbd>⌃</kbd> <kbd>Tab</kbd> — 在项目内的会话之间切换

## 常见问题

**必须每套都配吗?** 不用。启用你要的引擎,其余保持禁用,也不会被下载。应用里不内置任何引擎二进制 —— 只有你打开某套引擎时才去获取它。

**会话能中途换引擎吗?** 可以。handoff 会在任意引擎上启动一个同级会话,并带走一份持久的 Markdown 交接文档:计划和文件上下文转过去,对话记忆留在原会话里。
