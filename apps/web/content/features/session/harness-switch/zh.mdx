## 为什么需要两个引擎?

不同模型擅长的事情不一样。Claude 在长推理、大型重构上更稳;Codex 在小步快改、脚本类任务上更快。SuperOne 不强迫你选一个,而是把两套引擎都摆在桌面上。

## 怎么用

- 每个会话都有自己的引擎、模型和 effort,创建时选,中途也能切。
- 应用主题色会跟随当前引擎(Claude 暖橙、Codex 冷绿),一眼能分清是谁在说话。
- 记忆、斜杠命令、工具权限对两个引擎各自独立。

## 快捷键

- <kbd>⌘</kbd> <kbd>N</kbd> — 新建 Claude 会话
- <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>N</kbd> — 新建 Codex 会话
- <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>H</kbd> — 切换当前会话的引擎

## 常见问题

**两套 key 都必须配吗?** 不用。可以只跑 Claude、只跑 Codex,或两者都开,另一个就保持禁用。

**会话能中途换引擎吗?** 可以。计划和文件上下文会转过去,但对话记忆留在原会话里。
