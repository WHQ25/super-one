## What it does

Open a file next to the conversation — code with highlighting, images, plain text, Markdown, and Jupyter notebooks — without leaving for an editor.

## What it renders

- **Code** with syntax highlighting.
- **Markdown**, rendered rather than shown as source, including images and media referenced from the document.
- **Images**, at their real dimensions with zoom.
- **Notebooks** (`.ipynb`) as cells with their outputs, instead of as the raw JSON that a plain text view would show.

## Why it sits beside the chat

Reviewing a change the agent proposes means reading the file and the explanation together. Opening the file in an external editor puts them in two windows; opening it in the panel keeps the diff, the reasoning and the file in one field of view.

## FAQ

**Can I open the real file in my editor?** Yes — the context menu opens the path in your configured editor when you want the full thing.
