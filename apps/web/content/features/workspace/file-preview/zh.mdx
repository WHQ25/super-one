## 它做什么

在对话旁边打开文件 —— 带高亮的代码、图片、纯文本、Markdown,以及 Jupyter notebook —— 不必切去编辑器。

## 它能渲染什么

- **代码**,带语法高亮。
- **Markdown**,是渲染出来而不是显示源码,包括文档中引用的图片与媒体。
- **图片**,按真实尺寸显示并可缩放。
- **Notebook**(`.ipynb`)按 cell 及其输出呈现,而不是纯文本视图会给你的那一大坨 JSON。

## 为什么它在聊天旁边

审阅 agent 提出的改动,意味着要把文件和解释一起读。用外部编辑器打开会把它们分到两个窗口;在面板里打开,则让 diff、推理和文件处在同一个视野内。

## 常见问题

**能用我的编辑器打开真实文件吗?** 能 —— 需要完整功能时,右键菜单可以用你配置的编辑器打开该路径。
