## 它做什么

侧栏为打开的项目提供一棵文件树,并标注 git 状态,于是你不用切到终端就能看到哪些东西变了。

## 怎么工作

- 文件和文件夹标注了各自的 git 状态,已修改、新增和未跟踪的条目一眼可分。
- 树覆盖项目根目录以及你添加的工作区文件夹,于是根目录之外的目录也在同一个地方浏览。
- 选中文件会在预览面板里打开,而不是外部编辑器;右键菜单提供常规操作,也可以用你的编辑器打开真实路径。
- 这棵树也是 agent 看到的:它读的是同一份结构,于是"侧栏里的那个文件"和"agent 说的那个文件"是同一个文件。

## 常见问题

**远程项目也能用吗?** 能,远程文件树需要手动刷新 —— 远程节点的文件系统不会推送变更事件,所以刷新是显式的,而不是假装实时。
