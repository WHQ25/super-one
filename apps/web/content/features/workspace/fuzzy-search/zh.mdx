## 它做什么

按模糊匹配搜索项目文件,结果带排序并按目录分组。

## 怎么工作

- 从文件树顶部打开它然后直接输入,匹配结果随输入更新。
- 排序优先考虑文件名上的匹配,而不是路径深处的匹配,于是敲一个名字找到的是那个文件,而不是所有恰好含这些字母的目录。
- 结果按目录分组,于是十几个包里的 `index.ts` 这种同名文件不必读完整路径也能分辨。
- 方向键在结果间移动,<kbd>↵</kbd> 打开,<kbd>Esc</kbd> 关闭。

## 常见问题

**它搜索文件内容吗?** 不搜 —— 这是一个路径匹配器。内容检索是你会去问 agent 的事,而它正好有 grep 和 glob 工具。
