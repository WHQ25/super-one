## 它做什么

项目内的一个真终端,于是跑一条命令不意味着离开应用、丢掉当前的上下文。

## 怎么工作

- 终端在活动面板里以标签页打开,每个都以项目工作目录为根。
- 它是一个真正的 PTY,不是命令执行器 —— 交互式程序、TUI 和 shell 的表现与你自己的终端一致。
- 遵循 macOS 的键盘习惯;面板的开合带动画,于是终端出现时布局不会视觉上一跳。
- 终端配色跟随应用的外观设置,不需要单独配置。

## 为什么有用

agent 通过它自己的工具跑命令并把输出给你看。集成终端是反方向的那半:你想自己跑的命令,在同一个目录里,不必再对齐第二个窗口。

## 常见问题

**这就是 agent 用的那个吗?** 不是。agent 的 Bash 工具是独立的,它的输出落在对话记录里。这个终端是你的。
