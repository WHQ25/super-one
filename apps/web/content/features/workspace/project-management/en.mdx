## What it does

Projects are the top level of the sidebar. Open one, switch between them, and pin the ones you return to.

## How it works

- **Add a project** by browsing to a local path, cloning a repository, or picking one of your GitHub repos — the add flow searches your repos by name and offers a shallow clone when you only need the working tree.
- **Pinned projects** stay at the top; the rest are ordered by recency.
- **Every session is scoped to a project**, so opening one brings back its sessions, its drafts and its file tree rather than a global pile.
- **Workspace folders** let a project include directories outside its root. They persist per project and are fed into every harness turn, so the agent can read them without you re-granting access each session.

## FAQ

**Can I rename a project?** Yes — Edit Project covers the name and its workspace folders.

**What happens to unsent input when I switch?** Drafts are persisted per session, so a half-written message is still there when you come back.
