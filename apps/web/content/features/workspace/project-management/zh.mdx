## 它做什么

项目是侧栏的最上层。打开一个、在它们之间切换,把常回来的那些收藏起来。

## 怎么工作

- **添加项目**可以浏览本地路径、克隆仓库,或从你的 GitHub 仓库里挑一个 —— 添加流程支持按名字搜索你的仓库,只需要工作区时还可以选择浅克隆。
- **收藏的项目**留在顶部,其余按最近使用排序。
- **每个会话都归属某个项目**,于是打开一个项目会带回它的会话、草稿和文件树,而不是一堆全局条目。
- **工作区文件夹**让项目可以纳入根目录之外的目录。它们按项目持久保存,并在每一轮都送进 harness,于是 agent 能读到它们,你不必每个会话重新授权。

## 常见问题

**能重命名项目吗?** 能 —— Edit Project 里可以改名字和工作区文件夹。

**切换时没发出去的输入怎么办?** 草稿按会话持久保存,你回来时那条写了一半的消息还在。
