## 4. Required changes

Checked in this tree before the change, not taken from the catalog alone.
Desktop chat already launched through `resolveDesktopGrokLaunch`. Fork used
`resolveAcpLaunch`. Detect used `which` on the catalog command. Node
`run-turn.ts` sent `clientCapabilities: {}` and client version `0.0.0`. No
caller passed the harness catalog into `createAcpOpenCodeProductionRouter`, so
a harness-enabled `grok` was unused unless `SUPERONE_ACP_BINARY` or
`SUPERONE_ACP_COMMAND` was set. `Session.setPermissionMode` wrote the chip and
emitted `permission_mode_change` before `backend.setPermissionMode`. Section 5
is what closed those gaps.

| Priority | Upstream change | SuperOne change |
|---|---|---|
| P0 | `session/load` `_meta.noReplay` | Set `noReplay: true` on desktop load. Keep the drain only as a backstop. Do not add `session/resume` |
| P0 | Permission chip vs `session/set_mode` and `x.ai/yolo_mode_changed` | Emit the chip only after the RPC succeeds, and restore the previous mode on failure. Do not leave create-time plan state set when `set_mode` failed |
| P0 | Node process launch | Feed the harness-stored grok command, default args `agent stdio`, into the production turn runner. Fail closed when no binary exists. Do not simulate |
| P1 | Fork and detect | Use the same resolver as chat and login (`resolveDesktopGrokLaunch` / `resolveGrokRuntime`) |
| P1 | Node initialize and session meta | Real client version. For Grok, host fs and terminal off. Send explicit `yoloMode` and `autoMode`. Authenticate before `session/new` when a noninteractive method exists |
| P1 | `x.ai/folderTrust.interactive` | Add the trust dialog first, then advertise it. Answer `trust` or `reject`. Do not auto-trust. A missing advertisement must keep project rules, MCP, hooks, and skills unloaded |
| P1 | Generic Auto deny | Show the classifier deny on that tool. Keep the one-time honesty toast. Do not spoof `grok-desktop` |
| P2 | `_meta.contextWindow` | Optional picker only when the model lists more than one window. Send it only on `session/set_model`. Leave it unset to preserve |
| P2 | `x.ai/mcp/bearerTokenFile` | When the host supplies an HTTP MCP server that has a token file, put that absolute or `~/` path on the server `_meta`. Do not inline the secret |

No change for `acceptEdits` / `dontAsk`, host filesystem delegation, or a
