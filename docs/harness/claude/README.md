## Upstream

- Package: [`@anthropic-ai/claude-agent-sdk`](https://www.npmjs.com/package/@anthropic-ai/claude-agent-sdk)
  (JS half) plus one native `claude` binary package per platform
  (`@anthropic-ai/claude-agent-sdk-<os>-<arch>[-musl]`). Only the `latest` dist-tag
  is followed.
- Changelog: [claude-agent-sdk-typescript/CHANGELOG.md](https://github.com/anthropics/claude-agent-sdk-typescript/blob/main/CHANGELOG.md).
  Each release states the Claude Code version it is at parity with.
- Surface source: `sdk.d.ts` in the package. The control-protocol and message
  types in it are what the native binary speaks over stream-json.

## Integration shape

The SDK spawns the native `claude` binary and talks stream-json over stdio.
SuperOne always passes the binary path explicitly (`pathToClaudeCodeExecutable`)
from the harness runtime resolver, so the managed install and the bundled
binary are chosen by SuperOne, not by the SDK's own lookup.

| Runtime | Entry | Notes |
|---|---|---|
| Desktop sessions | `apps/desktop/src/main/session/backends/claude-backend.ts` → `apps/desktop/src/main/agent/claude-query.ts` | `buildClaudeOptions` builds every `Options`; the message loop in `createSessionQuery` maps SDK messages to `AgentEvent`. Permissions and elicitation in `claude-permissions.ts`. |
| Desktop warm start | `apps/desktop/src/main/agent/warmup-manager.ts` | `startup()` pre-spawns a process; `keyOf` decides reuse (see [contracts](contracts.md#warmup-reuse-key)). |
| Remote node (`apps/cli`) | `apps/cli/src/session/claude-turn-runner.ts` → `packages/claude` | `ClaudeLiveSession` / `runClaudeSdkTurn`; `createClaudeAgentEventMapper` is the node-side mapper. |
| Catalog probes | `apps/desktop/src/main/index.ts` (`CONNECT_CLAUDE`), `apps/desktop/src/main/agent/claude-models.ts`, `packages/claude/src/fetch-models.ts` | `maxTurns: 0` queries that read models, commands, account without a paid turn. |
| Fork and transcripts | `packages/claude/src/fork-session.ts`, `apps/desktop/src/main/agent/subagent-transcript.ts` | Pure-fs SDK helpers, no process. |

SDK messages are mapped in two places: desktop `claude-query.ts` and
`packages/claude/src/agent-event-mapper.ts`. A new message type usually needs
both; the ledger's Messages section says which mapper handles each.

constant and the `packages/claude` dependency differ.
