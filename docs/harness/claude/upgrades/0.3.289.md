# Claude Agent SDK 0.3.287 → 0.3.289

Status: executed · Date: 2026-10-05

## Scope

Upgrade the desktop, remote-node SDK and managed native runtime together.

## Upstream changes

SDK 0.3.288 and 0.3.289 track Claude Code 2.1.288 and 2.1.289.
Source: [upstream changelog](https://github.com/anthropics/claude-agent-sdk-typescript/blob/main/CHANGELOG.md).

## Surface diff

Published `sdk.d.ts` adds optional informational-message `tag` and per-model
`autoCompactWindow` settings. Other declaration changes are comments or whitespace.
Informational messages remain unused (backlog #1); their optional tag does not
change existing handling. The new settings field does not require a host control.

- Verified inventory, typecheck, Claude tests, managed-pin lockstep and mod recordings.
