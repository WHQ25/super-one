# Claude Agent SDK 0.3.293 → 0.3.296

Status: executed · Date: 2026-10-11

## Scope

Upgrade the desktop, remote-node SDK and managed native runtime together. No
new capability is adopted.

## Upstream changes

SDK 0.3.296 tracks Claude Code 2.1.296; 0.3.294 is a parity-only release.
Source: [upstream changelog](https://github.com/anthropics/claude-agent-sdk-typescript/blob/main/CHANGELOG.md).

- `sandbox` option now merges into an inline `settings.sandbox` block instead
  of discarding it (option wins; deny and credential lists combine).
- MCP tool descriptions and server instructions sent up front: default cap
  2,048 → 4,096 characters; through tool search: 16,384.
- MCP tool results: `_meta` over 1 MiB JSON is dropped except for SDK-server
  tools; MCP Apps `structuredContent` / `_meta` over 8 MiB is dropped; text past
  500,000 characters of a saved or cut result is dropped.
- The SDK passes named option values as `--flag=value`.
- `rate_limit_event` `allowed_warning` carries the `overage*` fields;
  `SDKRateLimitInfo.overageEnabled` added.
- Fixed: streamed text blocks losing `citations`; stale tool list after
  `mcp_set_servers`; `toggleMcpServer()` reported to the model as "disabled by
  the user".
- `updatedPermissions` over 4,096 entries counts as a denial; `pasted_content`
  over 1,000 entries is ignored.

## Surface diff

`sdk.d.ts` adds `AgentDefinition.autoCompactWindow`,
`claude_code_version` on the `initialize` response, `overageEnabled`, and
`onFailure: 'continue' | 'block'` on settings hook entries. `sdk-tools.d.ts`
adds `Read` `allow_large` and a WebSearch result `snippet` (hooks only). The
inventory reports only the existing `mcp_authenticate` /
`mcp_oauth_callback_url` drift. Every `ui_*` name in `mod-surface/wire.ts` is
still in the native binary.

## Required changes

- [DONE] Bump all SDK/native pins and the managed runtime constant;
  regenerate the lockfile.
- [VERIFY] Sandbox merge: SuperOne's inline `settings` carries no `sandbox`
  block (`buildClaudeOptions`, `claude-live-session.ts`, `run-sdk-turn.ts`), so
  the option still applies alone.
- [VERIFY] `--flag=value`: `makeClaudeSpawn` passes `args` through unchanged.

## Adopted capabilities

None. `claude_code_version` on `initialize` duplicates the `system/init` value
desktop already reads; `autoCompactWindow` needs the unused `agents` option.
`overageEnabled` and hook `onFailure` are backlog #17 and #18.
