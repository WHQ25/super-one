# Claude Agent SDK 0.3.321 → 0.3.330

Status: executed · Date: 2026-11-22

## Scope

Upgraded the desktop SDK, remote-node SDK, eight native binary packages and
managed runtime together from `0.3.321` to `0.3.330` (Claude Code `2.1.330`).

Sources checked:

- `anthropics/claude-agent-sdk-typescript` release notes (`0.3.322`–`0.3.330`)
- Installed `node_modules/@anthropic-ai/claude-agent-sdk/sdk.d.ts` declarations
- Native `darwin-arm64` `2.1.330` binary `--version` and `ui_*` strings

## Surface diff

From `bun scripts/harness-api-inventory.ts claude` and `sdk.d.ts` inspection:

- `Exports` adds `archiveSession`, `matchDeniedModels`, and `unarchiveSession`.
- `Options` adds `mcpServersDelivery?: 'argv' | 'initialize'`.
- `Settings` adds `permissions.workingDirectoriesExclude?: string[]` and `mcp_tool` hook `onFailure`.
- `reloadPlugins` options add `refuseIfBusy?: boolean`.
- Native `darwin-arm64` `2.1.330` retains every `ui_*` subtype in `packages/claude/src/mod-surface/wire.ts`.

The [API ledger](../api-surface.md) is updated to `0.3.330`.
