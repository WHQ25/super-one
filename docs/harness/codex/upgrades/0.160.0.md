# Codex 0.159.0 → 0.160.0

Status: executed · Date: 2026-10-05

## 1. Scope

Upgrade the desktop dependency and shared managed runtime to stable `@openai/codex` 0.160.0. Preserve unrelated worktree changes, direct stdio transport and existing protocol adapters. Do not enable Guardian experimental features or restart active sessions.

## 2. Upstream changes

Sources: [release](https://github.com/openai/codex/releases/tag/rust-v0.160.0) and [tag comparison](https://github.com/openai/codex/compare/rust-v0.159.0...rust-v0.160.0).

| Change | Classification | Integration |
|---|---|---|
| Incremental running-turn count (#49084) | runtime benefit | Same thread status notifications; no client changes. |
| SQLite startup/logging fixes, initialization errors and log-space reclamation (#49032, #49102, #49069) | runtime benefit | Verify connection initialization and failure handling. |
| Explicit provider catalogs become authoritative (#49135) | behavior change | Exact model IDs, no bundled fallback, invalidation after failed refresh, clear empty-catalog startup error. SuperOne custom providers fetch `/models` independently; that path does not inherit this fix. |
| Guardian history retrieval (#49036) | deferred | Disabled by default; requires parent Apps history tools and live policy checks. |
| Guardian handoff-aware root context (#49057) | deferred | Disabled by default; verify authorization revocations and delegation before adoption. |
| Pending subagent environments retained (#49075) | runtime benefit | Environment preparation failures propagate to workers. |
| Plugin manifest cache / shared HTTP pool (#49099, #49100) | runtime benefit | Existing plugin APIs remain unchanged. |
| Windows sandbox and background console fixes | runtime benefit | Windows smoke remains platform-specific. |
| TUI reconnect queue, provider defaults, history and projectless sessions | TUI only | SuperOne owns those client flows; no automatic adoption. |
