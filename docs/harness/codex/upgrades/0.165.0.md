## 3. Surface diff

`common.rs` method declarations: 184 at 0.163.0, 188 at 0.165.0. No method
removed. No method changed stability.

| Method | Stability | Decision |
|---|---|---|
| `feedback/save` | stable client request | unused |
| `thread/memory/read` | experimental client request | unused |
| `thread/sample` | experimental client request | unused |
| `thread/sample/cancel` | experimental client request | unused |

Protocol struct diff under `app-server-protocol/src/protocol` is 18 files,
+288/−18. Deletions are the image `result` field moving into a flattened
`GeneratedImageRef` (`result` for inline bytes, `fileId` for a stored file)
and a `Compacted` rollout payload becoming `Box`. Request structs SuperOne
sends (`thread/start`, `turn/start`, `turn/steer`, `model/list`) only gain
optional fields. `model.rs` is not in the diff.

`ImageGenerationItem` still serializes `savedPath`. Inline images still expose
top-level `result` via `#[serde(flatten)]`. File-backed images expose `fileId`
and may omit `result`. `inputImages` is absent on older items. SuperOne's
mappers read `savedPath`, `revisedPrompt`, `failure`, and `status` only.

`hooks/list` can return `preModelRequest` and `postModelRequest`.
`CodexHookEventName` does not include them, so `codex-hooks-service.ts` drops
those rows. Existing listed events still parse.
