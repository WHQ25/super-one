# Codex 0.167.0 → 0.169.0

Status: executed · Date: 2026-11-15

## 1. Scope

Upgrade the desktop dependency and managed runtime from `@openai/codex` 0.167.0
to stable 0.169.0. Keep the existing stdio client, prompt-suggestion sampler,
and approval behavior. Do not adopt provider administration, gateway device
login, mid-turn sampling, or answer-moderation presentation.

npm `latest` was **0.169.0** at lookup on 2026-11-15. `alpha` was
`0.171.0-alpha.5`. The stable publications in this range are 0.167.1
(2026-11-10), 0.167.2 (2026-11-11), 0.168.0 (2026-11-13), and 0.169.0
(2026-11-13). Alphas are not followed.
