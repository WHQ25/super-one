# Codex 0.169.0 → 0.171.0

Status: executed · Date: 2026-11-22

## 1. Scope

Upgrade the desktop dependency and managed runtime from `@openai/codex` 0.169.0
to stable 0.171.0. Keep the existing stdio client, prompt-suggestion sampler,
realtime timeline (`thread/timeline/list`), and approval behavior. Do not adopt
`modelProvider/default/set`, `thread/realtime/list`, `thread/search/stream`, or
answer-moderation hiding.

npm `latest` was **0.171.0** at lookup on 2026-11-22 (`alpha` was
`0.173.0-alpha.4`). The stable publications in this range are 0.170.0 and
0.171.0. Alphas are not followed.

  `codex-rs/app-server-protocol`

## 2. Upstream changes

| Version | Change | Tag | SuperOne implication |
|---|---|---|---|
| 0.170 | WebRTC negotiation for realtime voice calls in the TUI | none | SuperOne already owns desktop and mobile WebRTC realtime sessions. |
| 0.170 | Experimental support for identically named MCP servers across environments | deferred | Adds optional `environmentId` on MCP status/tool/resource/OAuth/elicitation schemas. Omitting it preserves legacy name-only matching. |
| 0.170 | Refreshed auth headers for OTLP HTTP exporters | none | Adds `headers_helper` and `headers_helper_refresh_interval_ms` on `OtelRequirements`. |
| 0.170 | WebSocket-to-HTTP fallback, MCP OAuth credential race fixes, permission preservation | benefit | Runtime stability improvements with no protocol changes required. |
| 0.171 | GPT-6.2 Sol and Astra added to model catalogs (Sol default) | benefit | Picked up automatically via existing `model/list` catalog probing. |
| 0.171 | TUI workspace enabled by default, `/rc` and `/remote`, `/statusline`, `codex exec --remote` | none | SuperOne owns workspace, remote node, and status surfaces. |
| 0.171 | Prevent late completion events from cancelling approvals for a newer turn; preserve aggregate diffs when steering | benefit | Runtime fixes for existing turn and approval flows. |
| 0.171 | `AgentMessageDisplay` structured into `version: 1` `show` / `hide` / `block` union | verify / deferred | Mapper still keeps `text` without hiding or blocking answers. |
| 0.171 | `modelProvider/default/set` | deferred | SuperOne owns provider configuration and must not mutate global `~/.codex/config.toml`. |
| 0.171 | `thread/realtime/list` and new `ThreadRealtimeItem` variants (`frame`, `turnInputAccepted`, `sessionEndInputSaved`, `observedAtMs`) | deferred | SuperOne continues using `thread/timeline/list` and filtering to `transcriptSegment`. |
| 0.171 | `thread/search/stream`, `thread/search/partial`, `thread/search/cancel`, `thread/search/stream/cancel` | deferred | SuperOne owns cross-harness session search. |
