# Cursor SDK 1.0.30 → 1.3.1

Status: executed · Date: 2026-11-15 · Commit: uncommitted

## 1. Scope

Bump `@cursor/sdk` and the five `@cursor/sdk-*` platform packages from `1.0.30`
to `1.3.1` (published 2026-11-03) in `packages/cursor` and `apps/desktop`.
`apps/cli/scripts/pack-npm.ts` reads the workspace pin, so the CLI pack follows
it. `packages/cursor` now depends on `zod` `^4.3.6` because `1.0.38` made zod a
peer (`^3.25.0 || ^4.0.0`).

Adopted on desktop local runs: manual compact (`SDKAgent.summarize`), queued
steer (`Run.steer`), and extra workspace roots (`LocalAgentOptions.dirs`).
`computerUse` tool calls render as “Computer”.

Left unwired: `AgentOptions.systemPrompt`, `local.fs` and its tree helpers,
`teamId`, no-repo cloud agents (`cloud: { repos: [] }`), true transcript fork,
and file rewind. The installed `1.3.1` public agent types still have no
fork or rewind method.

`1.3.0` and `1.3.1` public `agent.d.ts` / `options.d.ts` match. The official
changelog at <https://cursor.com/docs/release-notes/sdk> stops at `1.0.40`.
Later behavior is taken from the installed package README and
`dist/esm/*.d.ts`, plus <https://cursor.com/docs/sdk/typescript>.

integration calls was removed. The table is the subset that changes host

## 3. Surface diff

`scripts/harness-api-inventory.ts` has no Cursor extractor. The
[API ledger](../api-surface.md) records only the symbols this bump starts
using or explicitly leaves unused. The rest of the public surface is not
inventoried, so this document does not claim coverage.

| Interface | Published surface | Integration |
|---|---|---|
| `SDKAgent.summarize` | Local-only `Promise<Run>`. Throws `ConfigurationError` on cloud agents, before a saved conversation, and while another run is active. No `onDelta` | `cursor-runtime.ts#summarize`; `/compact` in `cursor-backend.ts` |
| `SDKSummaryMessage` | Stream message `running` / `completed` / `error`; `fallback: true` still frees context; `error` leaves the conversation unchanged | `cursor-event-map.ts` compact events. Summary text is not a chat bubble |
| `Run.steer` / `SteerAckOutcome` | `complete_delivered` or `revert_to_followup`. No persistent SDK queue. `confirm_steering` is not observable | Desktop `cursor.steer_queued` while a local turn streams |
| `LocalAgentOptions.dirs` | Merged with `cwd` (`cwd` first, duplicates dropped). `cwd` stays the shell and store scope. Create/resume only | Local create, resume, and workspace prewarm. Cloud omits `dirs` |
| `computerUse` | Tool-call type (click, type, scroll, key, drag, screenshot) | `toolDisplayName` exact match `computeruse` → “Computer” |
| `AgentOptions.systemPrompt` | Replaces the built-in harness prompt. Account-gated. Not persisted. Cloud and empty text throw | Unused. Host context stays on the first user message |
| `local.fs` and tree helpers | In-process file tools, local only | Unused |
| `AgentOptions.teamId` | Optional `x-cursor-team-id`; not persisted | Unused |
| Cloud `repos: []` | No-repo cloud VM, account-gated | Unused |

## 4. Required changes

| Upstream change | SuperOne change |
|---|---|
| Pin 1.3.1 and zod peer | Both manifests, lockfile, and `packages/cursor` zod dependency |
| `summarize()` / `SDKSummaryMessage` | Local compact. Delta summary text is dropped. Stream summaries emit `compact_boundary` and `status_indicator`. `/compact` is intercepted before `message_start` and is in `COMPACT_SLASH_HARNESSES` |
| `Run.steer` | Composer queue policy `always`. `cursor.steer_queued` while streaming. Images and empty text stay queued for a normal follow-up. `revert_to_followup` restores the item |
| `local.dirs` | Passed on local create, resume, and prewarm. `setAdditionalDirectories` returns false for an existing local runtime so the session rebuilds. Cloud returns true and does not rebuild |
| `computerUse` | Display name “Computer” |
| Capability flags | Desktop local `supportsCompact`, `supportsQueuedSteer`, and `supportsAdditionalDirs` are true. `supportsFork` stays false. Node one-shot turns report all three false |

## 5. Adopted capabilities

- [PLANNED] Local manual compact and automatic summary boundaries — desktop `/compact` calls `summarize()`; send-path `SDKSummaryMessage` uses trigger `auto`.
- [PLANNED] Queued steer on desktop local runs — `complete_delivered` consumes the queued message.
- [PLANNED] Additional directories — `local.dirs` on create, resume, and prewarm. `/add-dir` follows `supportsAdditionalDirs`.
- [PLANNED] `computerUse` display name.
- [VERIFY] Host context is still prepended once on the first non-slash user message. `systemPrompt` is not set.
- [VERIFY] Live content still comes from `onDelta`. Summary deltas are not pasted as `content_delta`.
- [DEFERRED] `systemPrompt`, `local.fs`, `teamId`, no-repo cloud agents, goals, true transcript fork, and file rewind — [backlog](../backlog.md).
