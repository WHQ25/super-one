# DeepSeek harness 0.1.7-rc.1 → 0.2.2-rc.1

Status: executed · Date: 2026-11-06 · Issue: [#144](https://github.com/WHQ25/super-one/issues/144)

## 1. Scope

Follow the upstream npm `next` tag, verified as `0.2.2-rc.1` (published November 4).
`latest` remains `0.1.0-rc.6`; the `alpha` channel is not followed. Both manifests
pin 136 DeepSeek packages: the dsh family at the target revision, Cordis 4.1.0,
group/include/loader 1.1.0, timer 1.2.0 and schemastery 3.19.0.

Primary sources: [npm metadata](https://registry.npmjs.org/@deepseek-ai%2Fdsh-agent),
[target release](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.1),
[source comparison](https://github.com/deepseek-ai/deepseek-harness/compare/dsh-v0.1.7-rc.1...dsh-v0.2.2-rc.1).
Published npm types/JavaScript are authoritative for this integration. The
previous JSONL compression default was checked directly against its npm
artifact as well as by replaying an original storage fixture.

manually (191 rows). The shared inventory script has no dsh extractor.

Removed packages `dsh-invariants` and `dsh-subagent-in-process-driver` leave both
manifests. New published peers and runtime dependencies are pinned together.
The subprocess runner still needs the Electron bootstrap environment patch;
its published hashed filename happens to remain unchanged, so the patch is
carried under the new package version and was checked after installation.

## 4. Required changes

- Upgrade both manifests and `bun.lock` with repository-pinned Bun 1.3.9. Preserve
  exact peer compatibility and the root version-keyed subprocess patch.
- Mount the new services/executors, adapt provider/persistence plugin exports and
  PTC launch configuration, and refresh all four reviewed presets.
- Keep upstream plugin-manager, plugin-market and schedule tool rows out of the
  vendored presets: the host owns them and does not mount their services.
- Preserve current session storage encoding. A real published `0.1.7-rc.1`
  compressed fixture guards the original physical format and successful append.
- Preserve model choice durably, make ordinary forks independent roots and adapt
  child task start/stop/failure handling to immediate activation.
- Match official model capacities (1,048,576 tokens) and Flash `addition-only`
  tool updates, instead of using the generic decimal-1M capacity fallback.

## 6. Verification

All scripted runtime tests use fake adapters; no live provider credentials or
network requests are needed. Tests involving persistence use Node 24, matching
upstream requirements. Electron 44.9.3 reports Node 24.22.0 in RunAsNode mode.

- Package and desktop Node typechecks: passed.
- Core/runtime, durable route resume, published-old Zstd fixture, ordinary fork,
  immediate delegation, stop/dispose, model-selection policy and trajectory:
  passed (targeted runs recorded during implementation).
- Preset/plugin catalog/dependency declarations: 15 tests passed.
- Tool/event/question/image/compaction/workspace/MCP/plugin boundary: passed after
  adapting old test expectations for step-time plan-tool admission and current
  plugin peer versions. Incompatible previous-minor plugins remain refused.
- Real Node PTC worker/birpc round trips: 2 tests passed with the explicit
  executable override, workspace-write/bwrap and full-access, relative cwd read,
  nested permission rejection and absence of the denied file write. These run
  outside the outer test sandbox, which interferes with inherited control fds.
- Sandbox positive/negative filesystem and shell controls: 6 tests passed outside
  the outer test sandbox, which otherwise makes the home fixture read-only.
- Desktop DeepSeek runtime and backend interactions/background: 54 tests passed;
  refreshed official model metadata tests: 4 passed.
- Main-only production Vite build: passed. DeepSeek packages remain external
  dependencies under the existing desktop externalization rules.
- Bun 1.3.9 frozen dependency installation, lock guard and diff whitespace: passed.

Not verified: live DeepSeek text/image/tool turn, packaged application end-to-end
boot/plugin import, Windows subprocess/PTC execution, and macOS execution.
Windows PTC's external Node must be 24.9 or newer. Linux source-runtime shell
confinement was exercised, but does not prove packaged execution.
